A01_BAS_comparison

After fitting our feature selection horseshoe prior-based model, we’d like to compare it with BAS model in order to verify if the two methods agree on which covariates are more useful in explaining the target variable.

1. bas.glm fit with a binomial family

With 23 predictors, \(2^{23} \approx\) 8.4 million candidate models – too many to enumerate exhaustively, so we use method = "MCMC" in BAS to stochastically search the model space. Later section will asses whether this search suffers from instability or not.

2. Parameter space convergence

Now we test the goodness of the MCMC search in the parameter space executed by BAS.

Convergence within one run.

BAS reports two independent estimates of each posterior inclusion probability:

  • probne0.RB : takes the set of distinct model visited containing the variable \(j\), use their marginal likelihoods, renomalizes and sum the mass of those models

  • probne0.MCM: it’s just the raw fraction of iterations the chain spent in some model containing variable \(j\) If the chain has converged, they should agree closely.

diag_df <- data.frame(renormalized = fit_glm_g$probne0.RN,
                       mcmc = fit_glm_g$probne0.MCMC)
ggplot(diag_df, aes(renormalized, mcmc)) +
  geom_point(color = "#185FA5", alpha = 0.7) +
  geom_abline(slope = 1, intercept = 0, linetype = "dashed", color = "grey40") +
  coord_equal(xlim = c(0,1), ylim = c(0,1)) +
  labs(title = "MCMC convergence check: PIP estimates should lie on the diagonal",
       x = "PIP (renormalized marginal likelihood)", y = "PIP (raw MCMC frequency)") +
  theme_minimal(base_size = 11)

Correlation between the two estimates is 0.9998, maximum absolute difference 0.028 – the points sit essentially on the diagonal, the sign this run has converged.

stability across seeds

We refit the identical model twice more with different random seeds and compare posterior inclusion probabilities (PIP) to check whether they agree or not.

run_seed <- function(seed) {
  set.seed(seed)
  fit <- bas.glm(y ~ ., data = df_bas, family = binomial(),
                 betaprior = g.prior(nrow(df_bas)), modelprior = uniform(),
                 method = "MCMC", MCMC.iterations = 100000)
  fit$probne0
}
pip_seed1 <- run_seed(1)
pip_seed2 <- run_seed(2)

BIC prior as a robustness check

We try another prior on the beta coefficients since, if the search is stable, the effect of the prior should vanish if the number of iterations is high enough.

set.seed(123)
fit_glm_bic <- bas.glm(y ~ ., data = df_bas, family = binomial(),
                        betaprior = bic.prior(nrow(df_bas)), modelprior = uniform(),
                        method = "MCMC", MCMC.iterations = 100000)

cmp_prior <- data.frame(term = fit_glm_g$namesx, g_prior = round(fit_glm_g$probne0, 3),
                         BIC = round(fit_glm_bic$probne0, 3))
cmp_prior$abs_diff <- round(abs(cmp_prior$g_prior - cmp_prior$BIC), 3)

With 100,000 MCMC iterations, PIPs move by at most 0.021 across three different seeds and by at most 0.006 between the g-prior and the BIC-based prior. Given the number of MCMC iterations, the search prove itself to be stable.

3. BAS vs Horseshoe: model comparison

Finally we compare the models selected by the two approaches, check on which coefficient do they agree and on which they dont’.

95% of the 22 predictors get the same signal/noise call from BAS’s model-space search and from the horseshoe’s continuous shrinkage – two structurally different estimation strategies (discrete model averaging vs. a single shrinkage prior) landing on the same handful of variables. The one disagreement, Class: Business (PIP 0.994, \(\kappa=\) 0.183), is a genuine borderline case in both methods (BAS just below its 0.5 cutoff, the horseshoe’s credible interval for it crossing zero in Section 03) – not a real contradiction between them.
